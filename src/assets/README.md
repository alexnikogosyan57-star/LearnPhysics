# Companion illustration

`mascot.webp` is a transparent web asset generated with the image generation tool using the user's supplied robot illustration as the visual reference. The supplied reference was available in the conversation, not as a local image file. The generated design preserves the ivory shell, olive joints, copper details and golden eye rims.

The original generated PNG is retained in `/workspace/generated_images/exec-b0d54344-5d13-422a-ab32-6bff7219a190.png` in this cloud workspace. The app uses a resized WebP export (approximately 73 KB).

This is one flattened illustration. CSS animates its whole image with restrained entrance transitions. It is not a layered character rig, articulated wave or 3D mesh. The hand's waving pose is part of the static illustration. Reduced-motion preferences disable the entrance animation.

No third-party stock asset URL or unverified external license is used for this generated asset. The moving delivery robot in `scene.js` is a separate original SVG rendering driven by the physics state.
